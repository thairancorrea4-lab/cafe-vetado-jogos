# Café Vetado · Jogos

Site jogável da embalagem fictícia **Café Vetado**: a caixa que vira jogo. São 12 jogos que funcionam direto no navegador, no computador e no celular.

**Passatempos**
1. Labirinto
2. Jogo dos 7 Erros
3. Caça-palavras
4. Sudoku
5. Palavras cruzadas
6. Conecte os pontos

**Direito aplicado ao Design**
7. Perguntas e Respostas
8. Escape Room de Embalagem
9. Caça ao Código Secreto
10. Trilha de Tabuleiro
11. Quiz sobre Café
12. Memória para Recortar

O site é uma única página estática (`index.html`), sem build e sem dependências. Na Vercel, basta importar o repositório.
